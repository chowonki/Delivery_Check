한빛탁송 자동 가져오기 연결

Chrome·Edge에서 아래 연결 기능을 한 번 설치하면, 탁송체크에서 오늘 날짜의 한빛탁송 엑셀을 바로 첨부할 수 있습니다.

연결 확장기능 내려받기

  1. 받은 ZIP 파일의 압축을 풀어 폴더에 보관합니다.
  2. Chrome은 주소창에 chrome://extensions, Edge는 edge://extensions를 입력합니다.
  3. 개발자 모드를 켠 뒤 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축을 푼 폴더에서 manifest.json이 있는 폴더를 선택합니다.
  4. 같은 브라우저에서 한빛탁송에 로그인합니다.
  5. WorkTool 탁송체크를 새로고침한 뒤 한빛탁송 오늘 엑셀 자동 가져오기를 누릅니다.

시작일과 종료일은 버튼을 누른 시점의 한국 시간 오늘 날짜로 설정됩니다. 로그인이 만료되면 한빛탁송 로그인 필요 오류를 표시합니다. 로그인했는데도 같은 오류가 나면 확장기능의 한빛탁송 사이트 접근 권한과 브라우저의 쿠키 설정을 확인해 주세요.

연결 기능은 위 WorkTool 주소에서만 동작합니다. 계정 비밀번호를 입력받거나 저장하지 않으며, 한빛탁송에 로그인된 브라우저로 엑셀을 요청합니다. 받은 엑셀은 WorkTool의 기존 파일 처리 기능으로 이 기기에서 읽습니다.

다시 가져오면 이전에 자동으로 첨부한 한빛 파일을 교체합니다. 직접 첨부한 파일은 유지하므로, 같은 자료를 수동 첨부했다면 중복 여부를 확인해 주세요. 지원 파일은 .xlsx이며, 다운로드·검증에 실패하면 기존 첨부 파일을 유지합니다.
